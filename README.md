# 💰 SIMKEU – Sistem Informasi Keuangan

A web-based financial management system designed to record transactions, monitor cash flow, and generate financial reports efficiently.

## ✨ Key Features

- 💸 **Income & Expense Management**
  Record and manage all financial transactions
- 📊 **Cash Flow Monitoring**
  Track financial inflow and outflow in real-time.

- 📈 **Financial Reports**
  Generate daily, monthly, and yearly reports.

- 🔍 **Search & Filter Transactions**
  Easily find transactions with advanced filtering.

- 🔐 **Authentication System**
  Secure login for system users.

## 🧠 Technical Highlights

- RESTful architecture for transaction management
- MVC pattern implementation (Laravel)
- Optimized database queries using Eloquent ORM
- Dynamic UI updates with AJAX
- Structured financial reporting logic

## 🛠️ Tech Stack

- **Backend:** Laravel
- **Database:** MySQL
- **Frontend:** Bootstrap / Tailwind
- **JavaScript:** AJAX

## 🎯 Project Purpose

This system is built to help individuals or small businesses:

- Manage financial records efficiently
- Monitor cash flow in real-time
- Reduce manual calculation errors
- Generate accurate financial report

## 🔄 System Flow

1. User login to the system
2. Input income or expense transactions
3. Data stored in database
4. System processes and calculates totals
5. Reports are generated dynamically

## ⚙️ Installation Guide

git clone https://github.com/ighfar-collab/simkeu.git
cd simkeu
composer install
cp .env.example .env
php artisan key:generate

### 🗄️ Database Setup

php artisan migrate
php artisan db:seed

### ▶️ Run Application

php artisan serve
